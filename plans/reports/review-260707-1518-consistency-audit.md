## Notes / verified-OK
- **Leads Prisma AND/OR filter** (comment-poller.ts:43-46, post-liveness.ts:62-65): correct and IDENTICAL in poller + sweep. The explicit `{ leadCollectorStatus: null }` arm correctly keeps active (null-status) collectors that Prisma `not` would otherwise exclude. Good.
- **Media ledger dual-branch** (agent-runners.ts:494-495, 559-565): `recordLlmUsage` (real image tokens) vs `recordMediaCost` (flat) is chosen consistently by `image.usage` presence across infographic AND storyboard; both guard on `!image.cached` (cached = no provider call = no charge). Consistent. The ONLY downstream inconsistency is the DAG badge (#1), not the ledger.
- **Infographic badge** is correct in BOTH image branches (no separate LLM planning call → `totalTok` is either the image tokens or 0, so the ternary always picks the right basis). Only storyboard (planning + flat frames) mismatches.
- **Video reference**: video animates storyboard frames (reference-conditioned via the first-frame anchor) and does NOT re-resolve a reference image — correct, not a gap.
- **Copy grounding FK** (service.ts:49,152,197): all three copy paths (generate / refine / variants) resolve `resolveLinkedKnowledge(post PK, campaign PK)` identically. Consistent.
